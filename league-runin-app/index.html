How this MVP calculates ranges

Highest possible place assumes a team reaches max points and counts teams that are already guaranteed above that total.

Lowest possible place assumes a team stays on current points and counts teams that can still overtake that total.

This is a fast "mathematical possibility" model based on points ranges. It does not fully simulate all fixture interactions.

Exact mode is fixture-aware and outcome-complete for smaller fixture lists.
