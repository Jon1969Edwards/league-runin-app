How to calculate

What each mode does
  • Fast range — quickest; uses min/max points only (not every fixture combination).
  • Exact — every win/draw/loss path; capped at 14 fixtures. Ties on points show as a rank band.
  • Monte Carlo — random samples for large fixture lists; tune simulation count.

Methodology (fast range mode)

Best rank assumes a team hits its max points and counts sides already guaranteed above that. Worst rank assumes it stays on current points and counts who can still pass it. Fixture-aware modes use tie bands when level on points.
